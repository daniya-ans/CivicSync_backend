# Smart Civic Issue Management System - Backend

Backend API for the Smart Civic Issue Management System built using Node.js, Express.js, and MongoDB Atlas.

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs
- Multer

## Installation

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

## Run the Server

```bash
npm start
```

The server runs on:

```
http://localhost:5000
```

## API Modules

- Authentication
- Complaint Management
- Image Upload
- User Profile Management
- NGO Verification
- Government Approval
- Worker Assignment
- Admin Management
